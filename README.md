# Codex Quota Menu

Нативное приложение для macOS, которое показывает состояние Codex прямо в строке меню: остаток квоты, число активных сессий и рабочую статистику за день. Если установлен OSY, оно также добавляет его локальную статистику в меню и отчёты.

Работает локально: без API-ключа, учётной записи в приложении и CLI после установки.

## Установка

1. Откройте [последний релиз](../../releases/latest) и скачайте ZIP для macOS.
2. Распакуйте архив.
3. Перетащите `CodexQuotaMenu.app` в папку «Программы» и откройте его.

После этого в строке меню появится индикатор вида `● 2  51%`: две активные сессии (Codex и OSY суммарно) и 51% оставшейся квоты Codex.

Никакие Swift, Homebrew или другие CLI-инструменты для использования не нужны.

> Первый запуск может быть заблокирован Gatekeeper, так как приложение распространяется без Developer ID и notarization. Откройте его через Finder с зажатой клавишей Control и выберите «Открыть».

## Что умеет

| В строке меню | В окне и отчётах | В настройках |
| --- | --- | --- |
| Остаток лимита по доступным окнам | История квоты за 7 дней | Обновление раз в 1, 5, 15 или 30 секунд |
| Активные, работающие и приостановленные сессии Codex и OSY | Работа нейронки, MCP, tools и skills | Недавние MCP рядом с индикатором |
| Время следующего сброса лимита | Добавленные строки кода и ARC AI-строки | Автозапуск при входе в macOS |
| Прогноз исчерпания при достаточной истории | Подробные отчёты по каждой сессии | Ежемесячная архивация отчётов |

### Статистика за день

В меню отображаются:

- время работы Codex по зафиксированным задачам;
- число вызовов MCP, tools и прочитанных skills;
- добавленные и удалённые строки исходников и конфигурации;
- число активных сессий и пять последних сессий;
- использованные MCP за последние пять минут — если включены в настройках.

Вложенные MCP-вызовы внутри tool-запросов `exec` тоже считаются. Для OSY доступны время работы, запросы, чаты, токены, стоимость и модели; содержимое чатов при этом не читается.

Пункт «История и графики…» открывает отдельное окно с динамикой квоты и работой по дням. Прогноз появляется после 15 минут истории; тренд за час — после накопления часа данных.

### ARC AI-строки

Для рабочих каталогов внутри Arcadia mount приложение считает содержательные строки, добавленные Codex. Корень mount определяется локально по файлу `.arcadia.root`, поэтому это работает с несколькими виртуально смонтированными репозиториями и не вызывает Git или GitHub.

Учитываются исходники и конфигурация — например, `.yaml`, `.yml`, `.json`, `.toml`, `.proto` и поддерживаемые языки. Пустые строки, комментарии и отдельные скобки не считаются.

## Отчёты и хранение данных

Все отчёты остаются на компьютере:

```text
~/Documents/Codex Quota Reports/
├── 2026-08-06/
│   ├── summary.json       # сводка за день
│   ├── summary.csv        # сводка для таблиц
│   └── sessions.json      # подробности сессий
└── Archives/
    └── CodexQuotaMenu-2026-06.zip
```

По умолчанию завершённые месяцы старше 30 дней автоматически упаковываются в ZIP. Внутри сохраняются дневные отчёты и `monthly-summary.json`; исходные папки удаляются только после успешного создания непустого архива. В настройках можно выбрать 30, 90 или 180 дней либо отключить архивацию.

Исходные журналы Codex в `~/.codex` приложение не удаляет и не архивирует.

## Приватность и ограничения

- Приложение не отправляет статистику или код в сеть.
- Оно не читает содержимое переписки для отчётов и не требует специальных разрешений macOS.
- Данные Codex берутся из локальных журналов `~/.codex/sessions`; для OSY используются агрегированная статистика и технические события из `~/.osy`.
- Codex не предоставляет публичный локальный API для квоты. Если будущая версия изменит формат `rate_limits`, индикатор может временно показать `Codex —` до обновления приложения.

## Для разработки

Для сборки нужен Xcode Command Line Tools:

```bash
./Scripts/build-app.sh
```

Готовое приложение появится в `dist/CodexQuotaMenu.app`. Для публикации ZIP используйте:

```bash
./Scripts/package-release.sh
```

По умолчанию используется ad-hoc подпись. Для распространения без предупреждения Gatekeeper соберите приложение с Developer ID и notarize его у Apple.
