# Codex Quota Menu

Небольшое нативное приложение для macOS: показывает в строке меню число активных задач Codex и остаток лимита по каждому доступному окну (например, `5ч` и `7д`).

Оно не запрашивает API-ключи, не передаёт данные в сеть и не требует специальных разрешений macOS. Информация читается локально из `~/.codex/sessions`; активной считается сессия без финального события `task_complete`, обновлявшаяся за последние 24 часа.

## Установка без CLI

В разделе [Releases](../../releases) скачай архив `CodexQuotaMenu-<версия>-macos.zip`, распакуй его и перетащи `CodexQuotaMenu.app` в `/Applications`. Swift, Homebrew и другие CLI-инструменты для этого не нужны.

Первый публичный релиз подписан ad-hoc подписью. Если Gatekeeper заблокирует запуск, открой приложение через Finder с зажатой клавишей Control и выбери «Открыть». После подписи Developer ID и notarization этот шаг не понадобится.

## Запуск

Требуется Xcode Command Line Tools (Swift 6):

```bash
swift run CodexQuotaMenu
```

После старта появится строка наподобие `● 2  86%`, где процент — именно оставшийся лимит. Частота обновления настраивается: 5, 15 или 30 секунд. В меню есть время ближайшего сброса, статус пяти последних сессий и ручное обновление.

## Статистика и отчёты

В меню выбери «Настройки…» и включи отображение недавних MCP. Там же можно выключить ежедневную выгрузку. По умолчанию приложение раз в минуту обновляет локальный срез статистики текущего дня:

`~/Documents/Codex Quota Reports/YYYY-MM-DD/`

- `summary.json` — суммарные показатели за день;
- `summary.csv` — та же сводка по сессиям, удобная для таблиц;
- `sessions.json` — подробности по каждой сессии: длительность задач, MCP и их названия, tools, прочитанные skills, добавленные и удалённые строки кода.

«Время работы нейронки» — суммарная длительность задач Codex, зафиксированная в журнале. Отчёты не содержат текст переписки или содержимое кода.

Подробные дневные отчёты можно автоматически архивировать в ZIP по завершённым месяцам. По умолчанию приложение сжимает месяцы старше 30 дней в `Documents/Codex Quota Reports/Archives/`, добавляет внутрь `monthly-summary.json` и удаляет исходные дневные папки только после успешного создания непустого архива. Период (30, 90 или 180 дней) либо отключение архивации доступны в настройках. Исходные журналы Codex в `~/.codex` приложение никогда не удаляет и не архивирует.

### ARC: содержательные строки, добавленные Codex

В корпоративной версии автоматически считается `ARC AI-код`: добавленные нейросетью содержательные строки исходников и конфигурации из событий `patch_apply_end`, только для рабочих каталогов внутри Arcadia mount. Сюда входят, например, `.yaml`, `.yml`, `.json`, `.toml`, `.proto` и файлы поддерживаемых языков. Корень mount определяется поиском файла `.arcadia.root` вверх от `cwd` сессии — это работает с любым числом виртуально смонтированных репозиториев и не зависит от имени папки. Git, GitHub и номер PR для фильтра не используются. Пустые строки, комментарии и строки, состоящие только из скобок или пунктуации, не учитываются. Поля `arc_repository` и `arc_ai_meaningful_code_lines_added` сохраняются в `summary.csv` и `sessions.json`.

Пункт «История и графики…» показывает расход квоты за последние 7 дней, работу по дням и сравнение текущего дня с предыдущим. Прогноз исчерпания появляется в меню после накопления как минимум 15 минут истории, а часовой тренд — после часа работы. История квоты хранится локально в `~/Library/Application Support/CodexQuotaMenu/rate-history.json`.

## Сборка

```bash
./Scripts/build-app.sh
```

Готовое приложение будет здесь: `dist/CodexQuotaMenu.app`. Перемести его в `/Applications`; в настройках приложения можно включить запуск при входе в macOS.

Скрипт по умолчанию использует ad-hoc подпись, поэтому приложение можно собрать на любом Mac с Xcode Command Line Tools. Для распространения другим пользователям без предупреждения Gatekeeper собери с Developer ID:

```bash
CODE_SIGN_IDENTITY="Developer ID Application: Your Name (TEAMID)" ./Scripts/build-app.sh
```

Затем notarize приложение у Apple перед публикацией релиза.

## Ограничение

Codex не предоставляет публичного локального API для квот, поэтому приложение опирается на формат журналов Desktop/CLI. Если будущая версия Codex поменяет формат `rate_limits`, строка меню покажет `Codex —`, пока парсер не будет обновлён.
